Root

Digital Vault · Hi Coffer AI Agent

Every business starts with Hi Coffer, a digital vault for individuals.
It finds scattered digital assets and organises what goes into the vault and how it is kept.

  1. 1

    Identify

    Registers PCs, external disks, USB drives and memory cards, and lists every file.

  2. 2

    Classify

    Sorts files by nature and type.

  3. 3

    Distinguish

    Separates duplicates, old versions, originals and sensitive files.

  4. 4

    Manage

    Sets retention and security grades; anything to delete is quarantined first and deleted only by the user.

  5. 5

    Vault

    Keeps only the assets the user selects in the vault and proves the originals.

Hi Coffer AI Agent Windows · PC version

It is a beta (β) version and is updated continuously.
Windows only; a macOS version will be released later.

What it does now

  • Registers storage media and lists every file (about 120,000 files on an external disk in 56 seconds, measured).
  • Creates area folders and a tidy-up plan with the HC-DAM standard.
  • Proposes where new files should go, runs only what you approve, and can undo it.
  • Quarantines duplicate copies and suspicious files.
    Nothing is permanently deleted.
  • Keeps the assets you choose encrypted in a vault and verifies the originals.
  • Records every change in a hash-chained ledger.

Before you install

  • Windows 10 or 11 with .NET Framework 4.8.
    (Built into Windows 10 1903 and later and Windows 11)
  • Installs for your user account; no administrator rights needed.
  • No wired or wireless network connection is needed.
    All processing and management happen on your local PC only. (A subscription version will be offered separately later.)
  • The trial is not code-signed, so Windows may show a warning.
    If a blue “Windows protected your PC” window appears when you run HiCoffer_Setup.exe:
    ① Click More info in that window.
    ② Click the Run anyway button that appears at the bottom of the window.
  • Always keep the vault recovery QR code file on external storage such as a USB drive.
