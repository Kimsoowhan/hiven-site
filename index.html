Root

디지털금고 · Hi Coffer AI Agent

모든 사업은 개인을 위한 디지털금고 Hi Coffer에서 시작합니다.
흩어진 디지털자산을 찾아내고, 무엇을 금고에 넣어 어떻게 관리할지 정리합니다.

  1. 1

    식별

    PC·외장 디스크·USB·메모리카드를 등록하고 파일 전체 목록을 만듭니다.

  2. 2

    구분

    파일을 성격과 유형으로 나눕니다.

  3. 3

    구별

    중복·구버전·진본·민감 자료를 가려냅니다.

  4. 4

    관리·유지

    보존·보안 등급을 정하고, 지울 것은 격리한 뒤 사용자가 확인해 지웁니다.

  5. 5

    금고화

    사용자가 고른 자산만 금고에 따로 보관하고 원본을 증명합니다.

Hi Coffer AI Agent Windows · PC버전

베타(β) 버전으로 지속적으로 업데이트 됩니다.
Windows만 해당하며, macOS버전은 추후 공개 예정입니다.

지금 되는 일

  • 저장 매체를 등록하고 파일 목록표를 만듭니다(외장 하드 12만여 개 56초, 실측).
  • 표준 분류 체계(Hi DAM)으로 영역 폴더와 정리 계획을 만듭니다.
  • 새로 들어온 파일의 정리를 제안하고, 확인한 것만 실행하며, 되돌릴 수 있습니다.
  • 같은 내용의 사본과 이상 파일은 격리합니다.
    영구 삭제는 하지 않습니다.
  • 고른 자산을 금고에 암호화해 보관하고 원본을 확인합니다.
  • 모든 변경을 해시 사슬 원장에 기록합니다.

설치 전에 확인

  • Windows 10·11, .NET Framework 4.8 필요.
    (Windows 10 1903 이후·Windows 11 기본 포함)
  • 유·무선 통신 환경이 필요 없습니다.
    모든 처리/관리는 로컬 PC에서만으로 가능합니다. (추후 구독버전은 별도)
  • 관리자 권한으로 실행하면 안 됩니다.
    HiCoffer_Setup 응용 파일을 그냥 실행하십시오.
  • 서명되지 않은 시험판이라 Windows가 경고 창을 띄울 수 있습니다.
    HiCoffer_Setup.exe 실행 시 파란색 ‘Windows의 PC 보호’ 창이 뜨면:
    ① 창 안의 [추가 정보]를 누르십시오.
    ② 창 아래쪽에 나타나는 [실행] 단추를 누르십시오.
  • 금고 복구 QR코드파일은 반드시 USB 등 외부 저장 매체에 보관하십시오.
