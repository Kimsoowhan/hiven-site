Root

Цифровое хранилище · Hi Coffer AI Agent

Все направления начинаются с Hi Coffer — цифрового хранилища для частных лиц.
Hi Coffer находит разрозненные цифровые активы и определяет, что поместить в хранилище и как этим управлять.

  1. 1

    Идентификация

    Регистрирует ПК, внешние диски, USB-накопители и карты памяти, а затем составляет список всех файлов.

  2. 2

    Сортировка

    Распределяет файлы по характеру содержимого и типу.

  3. 3

    Выявление

    Выделяет дубликаты, старые версии, оригиналы и конфиденциальные файлы.

  4. 4

    Управление

    Задаёт уровни хранения и безопасности; всё, что нужно удалить, сначала помещается в карантин и удаляется только после подтверждения пользователем.

  5. 5

    Хранение

    Помещает в хранилище только выбранные пользователем активы и подтверждает подлинность оригиналов.

Hi Coffer AI Agent Windows · версия для ПК

Это бета-версия (β), которая постоянно обновляется.
Только для Windows; версия для macOS будет выпущена позже.

Что работает сейчас

  • Регистрирует носители и составляет список всех файлов (по результатам замера: около 120 000 файлов на внешнем диске за 56 секунд).
  • Создаёт папки по областям и план упорядочения файлов по стандартной системе классификации Hi DAM.
  • Предлагает, куда поместить новые файлы, выполняет только одобренное вами и позволяет отменить изменения.
  • Помещает в карантин дубликаты и подозрительные файлы.
    Ничего не удаляется безвозвратно.
  • Шифрует выбранные вами активы, помещает их в хранилище и проверяет оригиналы.
  • Записывает каждое изменение в журнал, защищённый хеш-цепочкой.

Перед установкой

  • Windows 10 или 11 с .NET Framework 4.8.
    (Входит в состав Windows 10 версии 1903 и новее, а также Windows 11)
  • Проводное или беспроводное подключение к сети не требуется.
    Все операции обработки и управления выполняются только на локальном ПК. (Версия по подписке будет предложена отдельно позже.)
  • Не запускайте от имени администратора.
    Просто запустите файл приложения HiCoffer_Setup.
  • Пробная версия не имеет цифровой подписи, поэтому Windows может показать предупреждение.
    Если при запуске HiCoffer_Setup.exe появится синее окно «Система Windows защитила ваш компьютер»:
    ① Нажмите в нём «Подробнее».
    ② Нажмите кнопку «Выполнить в любом случае», которая появится внизу окна.
  • Всегда храните файл QR-кода восстановления хранилища на внешнем носителе, например на USB-накопителе.
