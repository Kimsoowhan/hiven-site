# hiven-site

HIVEN(하이븐) · HIVE-Group 홍보 홈페이지 원본. GitHub Pages로 https://hiven.co.kr 에 게시.

- index.html, 404.html: 정적 HTML (프레임워크·빌드 도구·추적 스크립트 없음)
- assets/css/site.css: 색·글꼴·배치
- assets/fonts: Pretendard (SIL OFL 1.1, 사이트에 쓰인 글자만 남긴 부분 글꼴), 사용 허가문 Pretendard-LICENSE.txt
- assets/img: 로고(투명), 심볼, 파비콘, 공유용 그림
- CNAME: hiven.co.kr
